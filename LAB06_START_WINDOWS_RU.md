## Что реализовано

Исходная папка содержала лабораторную №4. Добавлена необходимая для №6 основа: каталог книг, страница книги и API. Книги хранятся в памяти процесса; при перезапуске остаются три начальные записи. Существующие маршруты предыдущих лабораторных сохранены.

- `GET /books` — каталог, `GET /books/new` — форма, `POST /books` — создание книги.
- `GET /books/{id}` — информация о книге, `GET /api/books` и `GET /api/books/{id}` — JSON.
- Обязательные название, автор, год и жанр; название до 120 символов, год от 1450 до 2100.
- Собственное ограничение `@NoDigits` запрещает цифры в имени автора.
- При ошибке сохраняются введённые значения, показаны сводка и сообщения около полей.
- Корректная форма завершается редиректом на `/books`; flash-сообщение показывается один раз.
- `?lang=en` и `?lang=ru` переключают подписи и сообщения, язык сохраняется в сессии.
- `/books/999` возвращает HTML со статусом 404; `/api/books/999` — `application/problem+json` со статусом 404.
- `PageExceptionHandler.libraryName` добавляет общее название библиотеки в модель всех страниц книг — вариант 11.

## Сборка и запуск

Требуется **JDK 25**. Откройте PowerShell в папке проекта:

```powershell
$env:JAVA_HOME = 'C:\Program Files\Java\jdk-25'
$env:PATH = "$env:JAVA_HOME\bin;$env:PATH"
.\mvnw.cmd -B package
java -jar .\target\spring-lab-01-0.0.1-SNAPSHOT.jar
```

Дождитесь `Started SpringLab01Application`, затем откройте `http://localhost:8080/books/new`.
Перед повторной сборкой остановите запущенный JAR клавишами **Ctrl+C**, чтобы Windows не блокировала его перезапись.
